# 11.8: The start-up configuration, read-only, with its source

How to read this chapter: see [01-console-runs-the-installation.md](01-console-runs-the-installation.md).

The roadmap: "What the server needs to start (database and public address, where the key lives) stays in the configuration and shows read-only with its source." Spec 058 built the Configuration page for the server's own process. This chapter extends it to every process and makes the sources exact.

- **CSL-600** · built · **The server's settings** as `config.Inspect` reads them: every key of chapter 02.2, its value, and its source (default, the file and its line, the environment, or a `_FILE`), secrets as `(set)`, database addresses without their password, and problems by key and line, never with a value (spec 058, D9).
- **CSL-601** · built · The page reads the environment and the file again on each look, so it shows **what a restart would take**. New: when that differs from what the process **started with**, the row says "changes at the next restart" and shows both, the running value first. The process keeps the `Setting` list it started with for that. *Why:* an operator who edited the file sees at once that it is not in force yet. *Proof:* a test that changes a variable after the start.
- **CSL-602** · new · **One tab per process**: the node that answers, each other live node, and each worker. Nodes and workers report their list in their heartbeat row when they start and when it changes, at most once a minute (CSL-413). *Why:* the worker holds the owner's address, the backup folders and the grace; a node of role `worker` may differ from one of role `api`. *Proof:* a test with two nodes of different roles.
- **CSL-603** · new · **A setting that differs between live nodes is marked**, such as a different `PUBLIC_URL` or `MASTER_KEY_FILE`, since several nodes must agree on most of them. The list of settings that must agree is fixed in code: public address, instance name, the key ids each node holds (CSL-551), trusted proxies, session limits, contract grace, backup age. *Proof:* a test with two nodes that disagree.
- **CSL-604** · new · **The OpenTelemetry variables** that the exporter reads (`OTEL_EXPORTER_OTLP_*`, `OTEL_SERVICE_NAME`, `OTEL_RESOURCE_ATTRIBUTES`) are shown with the source "environment", and `OTEL_EXPORTER_OTLP_HEADERS` and any value holding credentials only as `(set)`. *Why:* they decide where traces go; headers often hold a token.
- **CSL-605** · new · **The worker's own settings** that the server never reads (backup interval and keep as defaults, the targets, the backup key's fingerprint) show on the worker's tab, from its report, with the source the worker gives.
- **CSL-606** · new · **Where a value came from outside Diffluence's sight**, such as a Helm value or a Compose default, the source is still "environment": the process cannot know what wrote its environment, and the page says so once, with the platform's file named (`compose.yaml` and `.env`, the chart's values, `/etc/diffluence/diffluence.env`). *Why:* honest about what can be known.
- **CSL-607** · new · **Each row links to what it means**, a line of `install.md` or `.env.example`, and, for the class S settings judged for security in chapter 03, one sentence why it cannot be changed here ("Outgoing calls to private addresses are set where the server starts, so a session cannot open your network"). *Why:* the reason is part of the answer, and the console should not look broken.
- **CSL-608** · new · **The configuration warnings of spec 056** (mail server, identity provider, publish folder, OPS-101) show on this page as the result of the last try at start, with when it ran, never trying again on each look. *Why:* each look would otherwise reach outside systems.
- **CSL-609** · new · **Nothing on this page can be edited**, and there is no route that writes a start-up setting. *Proof:* the route walker lists no write route under `/admin/configuration`; a test that the page has no form.
- **CSL-610** · new · **Who may see it:** administrators, as today. A system administrator sees the same; no value is more visible to them, because no secret is ever shown. *Why:* the page holds no secret by design.
- **CSL-611** · new · **What it costs:** see CSL-705.
- **CSL-612** · new · **The command stays** for a change before a restart: `diffluence config check` works with the server stopped, and the page says so beside the problems.
- **CSL-615** · not · **No editing of the configuration file from the console.** See CSL-1004.
