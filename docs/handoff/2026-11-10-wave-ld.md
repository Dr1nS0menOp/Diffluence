# Handoff: wave LD, 10 November 2026

Spec 050: what the first stress test on a real server showed, and what it changed. The report is `docs/reports/2026-11-10-wave-ld.md`; the stress test itself is `docs/reports/2026-11-10-stress-test.md`, cherry-picked onto this branch with its scripts in `scripts/stress/`.

## What landed

- Work that holds a database connection reads through it, in the eleven places spec 050 lists, and a request waits at most 10 seconds for a connection before it is told "busy".
- The feed, the bell and file search ask the permission rule only about the pages they could show. The feed's answer is proven equal to the former query (`TestTheFeedGivesWhatTheFormerQueryGave`).
- An IP address as `DIFFLUENCE_PUBLIC_URL` is refused at start with the reason.
- The install guide: PostgreSQL memory settings, `pg_stat_statements`, the audit lock's cost on a slow disk. Known limits: the server's numbers and this wave's.
- `scripts/stress/bench-data.sql` fills an empty database to the stress test's size in under a minute, for EXPLAIN.

## Gates

- `make check`: passed.
- `scripts/e2e`: 452 passed, 7 skipped. No picture changed.
- Full mutation check (`MUTATION_JOBS=2`): 535 caught, ending in `all mutations were caught`. Twelve mutations are new; seven older ones pointed at code this wave changed and were aimed at the new code, keeping what they break.

## For whoever lands this

- No migration and no new dependency. Spec 050; wave FU holds 049.
- `TestAPlainAddressIsWeakOnlyWhenOthersReachIt` lost its IP cases on purpose: an IP address is refused now, so `PlainToOthers` only meets names (`TestAnIPAddressIsRefusedAsThePublicAddress` holds them).
- `identity.Mailer.Send` and `identity.Policy.SecondFactor` take a `db.Querier` now. A fake mailer in a test needs the extra argument.

## Open

- **Re-run the stress test on the server** with this wave, and replace the server table in `docs/operations/limits.md`. Every "after" number here is one query in a container.
- **The audit lock (ARC-203)** is the product owner's to decide: spec 050, "Open for the product owner".
- A deeper call chain could still take a second connection; the 10-second limit makes that a "busy" answer, not a stop. A test that runs the whole suite on a pool of one connection would find the rest, but background workers share the pool, so it needs a way to give them their own first.
