# Handoff 2026-11-05: wave B, reading and getting around

## What was decided

- The product owner asked for the whole of blueprint 03 to be built, with one commit per wave, and tests when all waves are done.
- The product owner asked for the work to be shared out over agents. Each wave gets its own study and spec first, as before.
- ADR-025: how a page looks is page data, and one token holds both themes.

## What was done

- Spec 009 holds the study, 14 decisions and the plan.
- Migration 0006 adds page look, personal lists, shortcuts and the table of links between pages, which it fills from existing documents.
- Quick search, Recent and Favourites menus, help menu, Create menu.
- The spaces directory, Recent, Favourites, the space overview and Preferences as screens.
- The tree: filter, flat views, row menu, card on hover, keys. The sidebar: width, Overview, shortcuts, More.
- The page: read time, contents, heading links, Details panel, child pages, image viewer, reader mode, presentation, print, page look.
- A delete names what it touches, and the person who deleted can undo it for a short time.
- Single-key shortcuts with an overview, and a preference that turns them off.
- Tokens moved to `light-dark()`, with the same values.

## Found and fixed by the tests and pictures

- The close icon of the search chip was hidden by a rule meant for the search icon.
- The Create button fell off narrow screens.
- A controlled checkbox waited for the server, so it jumped back for a moment. Preferences now answer at once.
- After a search the box kept the focus, so `/` was typed instead of opening search.
- Pasting a heading address in the same tab did not jump, because the page does not reload.
- A time in the history moved the table by a pixel between runs, which made that picture fail now and then.
- Opening a row menu must not count as a visit, so it has its own route.

## Six failures on GitHub

Wave A failed on GitHub while it passed locally. The cause was a race in the tests, not a fault in the product. See the handoff of wave A. Browser test failures now show as annotations, which can be read without logging in.

## Unfinished, or seen along the way

- What is still open is in the status lines of chapters 1, 2, 3 and 8, with the wave it waits for.
- A tree with very many pages still loads at once (SPC-031). That needs a measurement under load, in phase 3.
- The header image is placed with a number, not by dragging it.
- Escape in a filter field first clears the field, and the second press closes the dialog. That is how the browser treats a search field.
