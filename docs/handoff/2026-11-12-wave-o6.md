# Handoff: wave O6, traces (2026-11-12)

Spec 060. What is built, what it costs and what is open is in `docs/reports/2026-11-12-wave-o6.md`; the measured numbers are in `docs/operations/limits.md`, "What traces cost".

## For whoever lands this

- **No migration.** New Go modules: `go.opentelemetry.io/otel`, `otel/trace`, `otel/sdk` and `otel/exporters/otlp/otlptrace/otlptracehttp` 1.47.0, all Apache-2.0, with their indirect modules listed in `docs/dependencies.md`. The OTLP protocol package links `google.golang.org/grpc` even though the exporter speaks HTTP; that is how the official package is built.
- **Off by default.** `DIFFLUENCE_TRACING=false`; an installation that changes nothing runs exactly as before. Where spans go is set by the standard `OTEL_EXPORTER_OTLP_*` variables.
- **`scripts/mutation-check.sh`** gains the mutations of spec 060 at the end. A merge with another wave's mutations keeps both lists.
- **Wave RS** (restore from the console) also touches the backup commands in `cmd/diffluence`. This wave only wraps each backup command in one span (`cmd/diffluence/tracing.go`), so the merge touches different lines.
