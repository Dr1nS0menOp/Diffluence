Spec 011, built on branch `wave-d`. Waves C and F were built at the same time, so this note says what the merge has to do.

## What was done

- **Pages:** owner, status, Verified, review date, labels, folders, link entries, blog posts, archiving, approvals, scheduled and silent publishing, publish options, What changed.
- **Templates:** the gallery, fields, instruction text, title patterns, steps in the form, ten starter templates, space templates, save from a page, import and export.
- **Moving:** moves and copies between spaces with their impact first, several rows in the tree with a Select mode, dropping a row on a space.
- **Spaces:** the Content screen with filters, a summary and a report, key changes with old keys, owners, home page, features, statuses, fixed labels, a picture, title alignment, delete with the key, the trash with search, sorting and bulk actions.
- **Search:** our own search language, filters in the address, tabs, breadcrumbs, a total, spelling from visible titles.
- **Safe text:** Close waits for the save, and text stays in the browser when a save fails.

New packages are `internal/features` and `internal/templates`. Migration 0008 is expand only.

## Blueprint 05 gaps closed here

Each has a test, and a mutation line where it is a security rule.

| Gap | What changed |
|---|---|
| GAP-001 | The trash of a space lists through `perm_hidden_pages`. A hidden item has no title, also not through search or the order, and shows as "A restricted page". Restore stays. A manual purge is refused, also when a hidden page sits below the item. Retention goes on |
| GAP-003 | A copy runs the check of a move: losing a restriction from above needs *manage restrictions*, also to another space and with Keep restrictions on. `GET /pages/{id}/copy-impact` lets the dialog say so before anything runs |
| GAP-022 | `GET /templates/{id}/files/{file}` belongs to the templates module, with the rule of who may read that template. A file of another page does not come through it, and `Evaluate` still refuses template pages |
| GAP-024 | The filter "links to pages that are gone" treats what the person cannot see as gone |
| GAP-028 | `ActionApprovalRead` is a named variant of the rule. `mayReadRound` no longer looks for a rule by name |

**Large copies** past 50 pages now run as a job with one transaction per page, because `audit.Record` holds its lock until commit. A page that fails is reported, and what is below it stays behind with it. Starting a space from a template past 50 pages still runs in one go.
