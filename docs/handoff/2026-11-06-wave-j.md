# Handoff: wave J, the rest of the editor, blocks and files

Date: 2026-11-06. Branch `wave-j`, not pushed, not merged. Study and plan: `docs/specs/020-rest-of-editor-wave-j.md`.

## What is new

- **Writing:** focus and Enter and Backspace between title and text, a click below the text, word count with selection, typing help with a preference, group headings and recent entries in the `/` menu, list styles per level, Whole word, spell check.
- **Paste and links:** pasted Markdown through the server, Undo back to the plain text, links that lead nowhere struck through.
- **Readers:** sort and filter a table without changing the page, a header that stays in view.
- **Files:** a picker of files on the page, tiles with type and size, a placeholder for what is gone, move and copy, blocked types, sort and filter in the list of a page.
- **Helpers:** office files as a PDF, a saved drawing can be changed.

No migration was needed, so number 0020 is free. No dependency was added.

## Things to know

- Two "the library does this" proofs failed and became code: `rule-undo.ts`, because TipTap forgets a shortcut as soon as its trailing node adds a line, and `setListKind`, because the list commands lost nesting.
- Typing characters such as arrows live in `typing.json`, next to the emoji list. They go into documents, and the design check rightly refuses them as icons in code.
- The sort arrow of a table is drawn in CSS. That button is made outside React, so an icon of the set cannot go in. A later change could move it to a React view.
- Moving a file changes who may read it: the rules of the new page decide. A tile on the old page then shows "no longer available" to someone who cannot see the new page.
- A copy goes through `Upload`, so limits and blocked types count, and it writes the bytes again rather than share a stored object.

## Not tested against the real thing

Only fakes were used for: Gotenberg's `/forms/libreoffice/convert`, Collabora's `/cool/convert-to/pdf`, and draw.io's `xmlpng` load field. Each needs one try with the real service. Changing a saved drawing has unit tests only, because the browser tests have no drawing service.
