## State

## For whoever lands this

- `internal/config/config.go` changed shape: `Load` calls `Inspect`, the readers (`str`, `boolean`, `integer`, `duration`, `backupAge`) note each value for the report, and `raw` reads the file after the environment. A setting added by another wave in the usual way (`l.str("NEW_SETTING", ...)` in `load`) is known in the file and the report without anything else.
- `compose.yaml` passes `DIFFLUENCE_PUBLIC_URL`, `DIFFLUENCE_SMTP_PORT` and `DIFFLUENCE_SMTP_TLS` as empty by default now; the application's defaults are the same values.
- `scripts/mutation-check.sh` has 19 new mutations at its end, and the mutation "an upgrade asks for no backup unless told" now targets the new lines of `backupAge`.
