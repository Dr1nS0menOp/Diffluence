## The product owner's choice

A mention on a public site is neutral text ("a colleague") unless the site shows names. Search of a site leaves mentions out the same way.

## What differs from the plan

- **Links.** A page must have a published parent, so imports publish first and give pages with links a second version. Undo records that version.
- **AC-3** says the link works once. The rest of the spec says 24 hours for that person, and that is what it does.
- **Rollback** refuses a build that holds a page which may no longer be public, instead of cutting it out: the search index and links of that build would still name the page.
- **A failed rebuild after a restriction takes the whole site down.** Waiting for someone to fix a build would keep the page public.
- **People.** Matching people is for bundles. Matching for other files went with EXC-032 to phase 11.
- **Bundles** hold the current version of each file, not its older versions.
- **Front matter:** `created` and `updated` are read and not used, because a date from a file proves nothing (SEC-353).
