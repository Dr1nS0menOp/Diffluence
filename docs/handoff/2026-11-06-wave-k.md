# Handoff 2026-11-06: wave K

Branch `wave-k`. See spec 021 for every line.

## What is built

- **Operations:** `/metrics` with its own token, `trace_id` from `traceparent`, `/readyz` for role `api` without the queue, `ETag` on files, default pool of 20, Helm chart in `deploy/helm/diffluence`, k6 script in `scripts/load/reading.js`.
- **Backups:** encrypted with AES-256 through `gpg`, key apart. `backup.sh` and `restore.sh` are bash now and take a key file. The drill proves refusal without a key, with the key beside the backup and with a wrong key, and runs every night.
- **Worker:** an event stops after six tries and waits in `event_failures`, with Try again in the console. A worker runs three jobs at once, plus one slot for short jobs. Each task has its own loop.
- **Blueprint 04:** every ARC line now says what is built. Checking them found real gaps, which were built: `MaxDeliver`, job slots, task loops, poll spread and an unlogged presence table. Office conversion came with wave J, tried against fakes only.
- **Blueprint 06:** of the High lines, only SEC-636 was really open, and it is closed. SEC-546 is `partly`.
- **Chapters:** see the table in spec 021.
