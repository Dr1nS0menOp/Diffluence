# Handoff 2026-11-06: wave M, links and tables

Branch `wave-m`. See spec 023 for every decision. No new dependency.

## What is built

- **Links that follow their page:** `pageLink` (text or tag) and `pageCard` hold an id only. `POST /pages/link-facts` answers per reader, and a hidden page gets "A page you cannot open".
- **Targets:** a link can lead to a heading or an anchor, on this page or another. `GET /pages/{id}/targets`.
- **Link dialog:** recent pages first, where on the page, how it shows.
- **Link tools:** open, copy, edit, remove and how it shows, in the row.
- **Placeholders:** `placeholderLink`, `page_placeholders` (migration 0023), and a list in Space settings that only shows when there is something in it.
- **Tables:** size picker, a handle and a plus for the row and column in use, dragging, Shift to select several, move from the menu, numbers, scaling with the page, caption, cells from text with tabs, no table in a table.
- **Exports:** `document.ResolveLinks` runs before every writer. Titles are for what the exporter may see, and on a public site only for pages on that site.

## For the product owner

- **Table button:** `/table` and the Table tool now ask for a size. 3 by 3 is ready, so Enter is enough.
- **A table inside a table:** on saving, the server keeps the words and drops the inner grid. That also holds for a Word import. Anyone with such a table sees it flattened after the next save.
- **Word and ODT:** a caption is a line of text there, and the numbers of a numbered table are left out in every export.
- **Old versions in an HTML export:** page links show as "Linked page", because nobody asked who may see what they linked to then.

## Left

## Not proven

- Two people following one placeholder at the same moment: the row lock decides, and no test runs them in parallel.
- Dragging on a touch screen, and a table of many thousands of rows.
- Pasting from a real spreadsheet. The tests paste text with tabs. Spreadsheets also put HTML on the clipboard, which takes the existing path.
- Copying a row with its handle and pasting it, in a real browser: selecting is tested, the clipboard step is the library's.
