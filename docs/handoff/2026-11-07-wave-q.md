# Handoff 2026-11-07: wave Q, the rest of the editor

Branch `wave-q`. See spec 027 for every decision.

## What is built

- **The row of tools:** tools that do not fit fold into More, from the end of the row. Nothing wraps, which also ends the narrow bar that covered the first line of the page.
- **Blocks:** a plus on an empty line, Browse all with previews, Copy link to this block, Turn into with the likely choices first, and back to text from a panel, section, spotlight or decision. Shift and a grip select a run of blocks, which move, duplicate and go together as one Undo. Saved blocks in the `/` menu, private unless shared.
- **Dragging:** a list item with what is nested below it, and a block at the edge of another makes columns, with a dashed line.
- **Images:** a corner to drag, a typed width, text around them, a border, a link, an image in a line of text, a question for a description, and a quiet count of images without one.
- **Pasted web pages:** images with their bytes in the clipboard are stored, and a note counts the rest. Lists from Word become lists.
- **Blocks with more options:** code (first line, folded for readers, language detection, Tab on several lines), a panel with your own emoji, a spotlight, a narrow sidebar split, wider columns, and a person and a date in a decision.
- **Charts:** axis and data columns, totals, titles, legend, height, smooth lines, data points with their own shape. The table is always there for screen readers. Removing a table asks about its chart. This wave also found that a chart in the editor did not follow its table until it was redrawn, which is fixed.
- **Language:** the language of a page, as page data, and the direction of a line.
- **Safety of documents:** `document.Upgrade` runs on reading, and a block from a newer release stays as a note.
- **The shortcut list** now has the keys of the editor and of tables.

## Lines that only needed a status

EDT-050 (a tick while reading is a silent version) and EDT-125 (a date in a task sets its due date) were built in earlier waves.

## Left

- **EDT-006** (hidden tools with a floating bar) and **EDT-080** (a bar at the image): these go against spec 008, D3, so they wait for the product owner.
- **EDT-074:** a caption stays plain text. Formatting in it needs a caption of its own in the document model.
- **EDT-020:** blocks that show data of a page have a hint and no live preview.
- **EDT-058:** a block without any text, such as an image, cannot get a link.
- **EDT-143:** blocks and marks come along through the clipboard, and a file keeps pointing at its own page.
- **EDT-149:** a comment while editing on a page that was never published.
- **EDT-150:** typing in 100,000 words was not proven.

## Not proven

- Word and Google Docs were tried on samples of their HTML, not on real files, and nested lists arrive flat.
- Language detection is a rough guess: a small Python sample came out as another language in a test. The writer can change it.
- Dragging a corner of an image, and the dashed line itself, have no browser test. The drop that makes columns has.
- `document.Upgrade` has no real step yet, because version 1 is the only one.
- A block that comes back from `unknownBlock` is left for phase 8, and has to pass `Normalize`.

## For the product owner

- **EDT-006 and EDT-080:** do you want floating bars after all? That changes spec 008, D3, and the design standard.
- **Emoji:** the picker is in More formatting, not a button of its own, so the row still fits a window of 1280 pixels.
