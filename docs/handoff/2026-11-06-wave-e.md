# Handoff: wave E, blocks and files

Date: 2026-11-06. Branch: `wave-e`. Spec: `docs/specs/012-blocks-and-files-wave-e.md`.

## What is built

Dynamic blocks with one server route that answers per reader, page facts, excerpts, includes with a loop and depth stop, anchors, charts, media, a Files screen, file versions, rename, text preview, a zip of all files, the same-name question, and optional drawing. The status lines in `docs/blueprint/03-functional/05-dynamic-blocks.md` and `06-files.md` say what each requirement still misses.

## At merge

1. **Migrations.** This wave's migration is `0016_blocks_and_files.sql`, because `0009_reserved_wave_e.sql` is merged and may not be edited. Versions must be contiguous, so `0011` to `0015` are placeholders on this branch. Specs 014 and 015 plan real migrations as 0011 and 0012, which clash with these. A database that applied a placeholder skips the real migration of that number, so settle this before anyone runs it on data they keep.
2. **Shared files** changed: `web/src/app.tsx`, `web/src/api.ts`, `web/src/locales/en.json`, `web/src/components/frame.tsx`, `internal/httpapi/server.go`, `internal/app/app.go`, and the signature of `webui.Handler`.

## Decisions for the product owner

1. **PdfCraft was left out by mistake.** This wave took it for AGPL-3.0, but the README of `storytold/pdfcraft` says "dual-licensed under MIT or Apache-2.0", as ADR-026 says. It is allowed. PDF stays a download until a follow-up measures the web build and embeds it.
2. **draw.io works self-hosted.** In Chromium, `jgraph/drawio` in embed mode gave `init`, `load` and an `xmlpng` export, with 15 requests and none to an outside host. Chromium blocks a public origin from framing a private address, so the probe turned that check off. The stencil terms are still unchecked.

## Not built

Office preview and its route, PDF viewer, Mermaid (replaced by draw.io), changing a saved drawing, section contents, activity tabs, popular pages and labels, related and recent labels, synced block editing, snippet variables, contribution table, person card, people list, space files block, create from template, rotating cards, timeline, block bar and width controls, blocked file types and limits per space, attachment references and events, moving and copying files, bulk delete, upload progress, dropping on a tile, block templates.

The drawing dialog has unit tests for its message checks, and the real service was tested by a separate probe. No browser test runs the dialog against draw.io.
