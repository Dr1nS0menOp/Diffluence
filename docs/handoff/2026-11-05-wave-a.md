# Handoff 2026-11-05: wave A, the editor

## What was decided

- The product owner agreed that the four waves come before phase 3, and approved extra TipTap packages (ADR-024).
- **Every phase now starts with a large study and a detailed plan.** See "Every phase starts with a study" in `docs/blueprint/09-way-of-working.md`. Spec 008 is the example. This is a hard rule in `CLAUDE.md`.

## What was done

- Spec 008 holds the study, 12 decisions, 18 planned features, the document format, the build order, the test plan and the risks.
- The document format gained `panel`, `expand`, `columns`, `column`, `decision`, `status`, `date`, four marks, and attributes for alignment, indent, images, cells and code. `internal/document/attrs.go` now holds all rules for attributes.
- `web/src/components/editor/` replaces the single `editor.tsx`, with one job per file.
- Slash menu, Insert dialog, block handle and menu, text colours and highlights, alignment and indent, panels, sections, columns, decisions, status marks, dates, emoji, the new link dialog, image options, table tools, code options, find and replace.
- The row of tools is one Tab stop. `Menu` follows Home, End and letters, and has radio items.
- One new dependency, `@tiptap/suggestion`. Everything else is our own (see `docs/dependencies.md`).
- Chapter 4 of blueprint 03 has its statuses updated, and its keyboard table matches what is built.

## Found and fixed by the tests and pictures

- A stale position in the block handle crashed the editor after the text got shorter. An edit now clears it, and a check guards it.
- A plain string given to `insertContent` is parsed as HTML, which Trusted Types refuses. Text goes in as a node. **Keep doing that.**
- Moving a block merged with the typing before it in Undo. Block commands now close the history step.
- Changing the text style dropped alignment and indent.
- Updating a node without content replaces it, which ended its selection and hid its tools. `updateSelected` keeps it.
- The handle covered the first letters of the text. It now sits in the margin.
- The account button's visible initials were not in its name (WCAG 2.5.3). It passed for the administrator only because "A" is in "Account". Initials now come from the style sheet.
- Comparing versions no longer glues list items together.

## Unfinished, or seen along the way

- **The drag test that failed once** turned out to be a race in the tests, seen again on GitHub in six tests. TipTap gives the focus back in the next frame, and ProseMirror puts the cursor back 20 ms after focus. A test that typed at once lost that race on a slow machine. `editorSettled` in `web/e2e/helpers.ts` waits for it. Failures on GitHub now show as annotations, which can be read without logging in.
- What wave A left out is in the status lines of chapter 4 as "partly", with what is missing.
- Multi-block selection, copy link to a block and the plus button in the margin wait for later waves.
- A `details` stays closed when printing. Print belongs to wave B.
- `useEditor` receives a new extensions array on each render, so it calls `setOptions` each time. Harmless so far, and worth a look if typing ever feels slow.
