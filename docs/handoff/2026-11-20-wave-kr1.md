## For whoever lands this

- The rename is mechanical and was made by a script kept outside the repository (`kr1-rename.sh`, held by the coordinator). Each open branch (SC4, UR1 and the others) runs it on its own tree, commits, and only then rebases onto this commit, so the rebase sees the same lines on both sides:

  ```
  bash kr1-rename.sh <path of the worktree> --format
  ```

  `--format` runs prettier in the worktree's dev containers; the script then prints the `gofmt -w cmd internal` step, which goes to the build machine with the other Go steps. A second run changes nothing. A branch that adds a new file naming the old name gets it renamed by the same run.
- A branch's own Compose project and database volume were made with the old role names; after the rename, `scripts/dev down -v` and `up` once, or the tests cannot log in.
- `git grep -i diffluence` finds only the records listed in spec 095 D9. `git grep -i confluence` gives the same lines as main.
