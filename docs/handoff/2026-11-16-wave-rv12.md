# Handoff: wave RV12, who a rule runs as (16 November 2026)

## State

- **Built:** spec 092. Only the holder of a rule changes it or switches it on; others who manage it switch it off, delete it, or take it over with `take_over: true` on `PUT /api/v1/rules/{id}`. A test run reads pages as its caller unless the caller holds the rule. Conditions need a page: a run without one does nothing (`conditions_need_page`), and such a rule cannot be switched on. The report is `docs/reports/2026-11-16-wave-rv12.md`.
- **Migrations:** none.
- **Upgrade:** rules with conditions under a schedule, an incoming webhook, a group or a space trigger stop acting; their run log says why (CHANGELOG, Upgrade impact).

## For whoever lands this

- The new audit action is `rule.taken_over`, also sent as an outbox event of that type. Nothing consumes it yet.
- `Input` gains `take_over`; `docs/api/routes.txt` and `openapi.json` do not change.
- The rule editor shows the server's message on `409 rule_held`; there is no Take over button yet.
