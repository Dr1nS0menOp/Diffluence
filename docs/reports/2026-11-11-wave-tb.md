# Wave TB: the line through a table (2026-11-11)

**Asked:** while editing a table, a line ran through the first row.

**Found:** the drop markers for dragging a row or column (`.table-drop`) were always
visible. Their kind class, `row` or `column`, matched the global layout classes, whose
`display: flex` overrode the `hidden` attribute. The handles and plus buttons of the line in
use had the same fault when they should hide.

**Fixed:** the kind classes are now `row-line` and `column-line` (spec 055).

**Proof:** a new browser test that failed first with two visible markers and passes now;
the table and editor browser tests pass (35); pictures in light, dark, right to left, a
scrolled wide table and a narrow window show no stray line. No mutation: the fix is a class
name, checked by the browser test.

**Seen, left alone:** on a narrow window the block handle of the paragraph above can overlap
the table's corner, and the row handle can touch the first letters of a cell.
