# Report: wave SC4, the administration (spec 081)

## What was asked

Rebuild the administration as blueprint 03 arranges it (ADR-045, ADR-048), per the twelve steps of spec 081, on top of the frame of SC1. ## Through the API

Spec 081 has a table of every section with the routes that read and change it, and the rule each enforces. Every part of every section has both; no route was added (D21). A token still only reads, as RV10 decided; a session reaches everything (D22).

D21 to D30 in the spec. In short:

- **D21** no route added; the spaces filters stay in the browser over the full list.
- **D22** a token still only reads the administration; changing it through a token waits for the MCP spec.
- **D23** `.note` keeps its look outside the administration (narrows D4).
- **D24** the empty block for Automation, Templates and Document control waits for SC5.
- **D25** tool rows are a wave of their own.
- **D26** a shut group shows the section opened from elsewhere, until its heading is pressed.
- **D27** mail switches and export formats save with Save.

- **D29** Instance permissions says where a permission is changed.
- **D30** General starts with a part heading, and the rule that hid a section's first heading is gone.

## What was found while building

- The class `section-head` already existed (the head of a list on Overview, Insights and People of a space); the head of a settings section is `settings-section-head`. The design check does not see two rules for one class name meeting on one element; a reviewer of a new class should grep for it first.
- A sticky row inside a scrolling sidebar sticks at the edge of the sidebar's content box, under its padding, so the header row sticks at minus the padding.
- Sections that wait for the answer of `/system/capabilities` (Automation, Import a space) push later entries down after the first look; the scroll into view runs again when the number of entries changes.

## What was not proven

- The tool rows (ADM-103) are not built, so the filters of Users and the Audit log are as before.
- A notice of news (dismissed per person, NAV-150) has no use yet and is not built.
- Bold parents in tables (ADM-108 to ADM-110), the sort arrow in the accent colour, and narrow number fields as wide as their content are not built.
