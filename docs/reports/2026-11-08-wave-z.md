## How the status of 05 and 06 was checked

436 lines were not marked built. A script looked for every name a line puts in backticks in the code: 95 lines named only things that exist. Lines without names were paired with test names by shared words, and each pair was read by hand. Waves N, Q and M built some lines under other names (`saved_blocks`, `pageLink`). In WSL, `git grep` does not work inside a worktree whose `.git` file points at a Windows path, which made the first pass report everything as missing. The second pass read the files directly.

Result: 05 went from 152 to 265 built of 298, and 06 from 153 to 284 of 429. 31 lines keep their wave label because nothing proved them; spec 035 lists them.
