## Load budget

No feature adds a query per read. The mail on a credential change costs one query and one queued mail per change. The limits are in memory. The browser cleaner walks the document once per batch of remote changes.

## Gates

- `make check`: passed (format, vet, staticcheck, vulnerabilities, licences, web checks, the collab service's tests, Go tests with the race detector).
- `scripts/e2e`: 434 passed, 7 skipped. `E2E_COLLAB=1 scripts/e2e collab.spec.ts`: 7 passed.
- The full mutation check with `MUTATION_JOBS=2`: 452 caught, none missed or broken, ending in "all mutations were caught". Two new mutations first did not compile and were rewritten.
- Short fuzz runs: `FuzzParseFilter` 30 s, `FuzzHTMLImport` 60 s, `FuzzImportArchive` 45 s, without findings. An early `FuzzImportArchive` run flagged a harmless name with `..` inside it, and its check was corrected.
- `git status` of the main checkout stayed clean.
