# Wave O6: traces with OpenTelemetry

Written for: the product owner and whoever builds the next operations wave.

Wave 6 of spec 048, planned in spec 060. It builds OPS-088 and OPS-092 and leaves OPS-091 for the test server.

## What is built

- **Off by default.** `DIFFLUENCE_TRACING=false` unless an operator switches it on. Off, nothing of tracing runs: no middleware in the chain, no span tracer on the pool, no headers on events, no wrapping of the log (`TestOffDoesNothingAndChangesNothing`, which also proves the span helper allocates nothing).
- **Where spans go** is the standard of OpenTelemetry: `OTEL_EXPORTER_OTLP_ENDPOINT` and its siblings, read by the exporter. OTLP over HTTP with protobuf, sent in batches in the background.
- **Sampling** is parent-based at `DIFFLUENCE_TRACING_SAMPLE`, 10% by default; a request inside a sampled trace from a proxy stays sampled. A share outside 0 to 1, NaN included, refuses the start.
- **Spans**:
  - a request, named by its route pattern (`GET /api/v1/pages/{id}`), or by its method when it has no route;
  - a query, named by its operation and first table (`SELECT pages`), skipped inside a trace that is not kept;
  - an event sent and handled, with the trace in the NATS headers, so the handling shows under the publish;
  - a job, a periodic task, the audit sealer (with how many it sealed) and each command of the backup worker, which flushes before it exits.
- **No content.** No path, query string, id, SQL statement or value, title, text, name, email address, token, client address or user agent. A failure records `error` or a SQLSTATE code, never the message. `TestTracesOfTheWholeApplicationHoldNoContent` runs the whole application with tracing on, creates a person, a space, a page with text, searches, uses a token, runs jobs and the sealer, and checks every span name, status and attribute.
- **Logs and traces joined.** While tracing is on, a log line written inside a span carries `trace_id` and `span_id`.
- **Log events as an interface (OPS-092).** `monitoring.md` lists the messages an operator may build on; `TestEveryListedLogEventIsStillWritten` keeps the list true.

## What it costs

Measured in the development container with `go test ./internal/tracing -bench .`; the numbers are in `docs/operations/limits.md`. Off: nothing. On at the default share: about 1.3 µs per request and 33 ns per query in the nine requests in ten whose trace is not kept, about 17 µs for a request of ten queries whose trace is kept. Not measured under load on the server.

## Decided during the wave

The decisions are D1 to D11 of spec 060. The ones that go beyond the study:

- **No ids in spans either** (D6). The study allowed ids; a person's id joined with the database names the person, and the route pattern already says what kind of object was touched.
- **No contrib modules** (D11). `otelhttp` and `otelpgx` add attributes spec 060 forbids; our middleware, query tracer and NATS carrier are a few lines each.
- **OTLP over HTTP** (D3). The OTLP protocol package still links its gRPC stubs, so gRPC and its modules are in the build.
- **The outbox relay publishes in its own trace** (D8). Carrying the request's trace through the outbox would need a migration.
- **Queries inside an unsampled trace make no span.** It cuts their cost from about 1.6 µs to 33 ns.

## Not proven

- A real collector and back end (Tempo, Jaeger, a hosted one): only the SDK's in-memory exporter.
- checkmk (OPS-091): needs the test server.
- The overhead under load, and the batcher's behaviour with a collector that is down under load: wave 7.
- Spans of the editing service (Node.js): not instrumented.
- Most log lines are written without a context, so they do not carry the trace; the request line and lines written with a context do.

With the shortcut removed, the query still made a span, only one that is never recorded, so the exporter saw no difference. `TestAQueryInATraceNotKeptMakesNoSpan` now also checks that no span is started at all; it fails with the mutation applied by hand, and the mutation run of `internal/tracing` caught all 18.
