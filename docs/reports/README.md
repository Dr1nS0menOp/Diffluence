# Reports and research notes

Every builder writes its final report here, and every study keeps its research notes here, so the next session can read them instead of relying on memory. Specs in `docs/specs/` say what is built; handoffs in `docs/handoff/` say what is next; these say what was found, measured and weighed.

Name a file `YYYY-MM-DD-<topic>.md`. Write it for a later build session: what was tried, the numbers, what was not proven, what is open.

Two things never go here, because the repository is public:

- An unfixed weakness, or steps that would exploit it. Name it here only after the fix has landed.
- Anything personal about the product owner or anyone else.
